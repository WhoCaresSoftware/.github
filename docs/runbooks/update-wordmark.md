# Update the profile wordmark

Use this when the brand wordmark changes.

## Before you start

- Read access to the `@whocaressoftware/brand` package.

## Steps

1. Take `identity/wordmark/svg/website-wordmark-light.svg` and
   `identity/wordmark/svg/website-wordmark-dark.svg` from the new brand release.
2. Copy them into `profile/assets/` as `wordmark-light.svg` and `wordmark-dark.svg`.

## Verify

The organization page shows the new wordmark in both light and dark appearance.
